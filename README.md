# Terminal Weather

**Python** · **v0.1.0**

_Terminal weather report for any city via wttr.in_

---

## Features

- Current conditions, temperature and wind for any city
- Hourly and 3-day forecast modes
- Zero dependencies - uses urllib (stdlib)

## Installation

```bash
git clone https://github.com/DevCode01/terminal-weather.git
cd terminal-weather
```

## Usage

```bash
./terminal-weather.py Clermont-Ferrand
```
